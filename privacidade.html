Política de Privacidade

Última atualização: 4 de novembro de 2026

1. Quem somos

O dark-canais é uma ferramenta de uso pessoal que publica vídeos nos canais do YouTube do próprio dono do projeto. Contato: canaisdarkdozatch@gmail.com.

2. Quais dados acessamos

Com a autorização do dono da conta, pelo login oficial do Google (OAuth), o aplicativo usa a API de Dados do YouTube para:

  • enviar vídeos, títulos, descrições, tags e miniaturas para os canais do próprio dono;
  • definir a data de publicação e a visibilidade desses vídeos;
  • ler a lista de vídeos e canais da conta autorizada, apenas para conferir os envios.

O aplicativo não acessa dados de outros usuários, não lê comentários nem mensagens privadas e não coleta dados de espectadores.

3. Como os dados são guardados

O token de acesso fornecido pelo Google fica salvo apenas no computador do dono do projeto. Ele não é enviado para nenhum servidor nosso nem compartilhado com terceiros.

4. Compartilhamento

Não vendemos, alugamos nem compartilhamos dados com ninguém. Os dados só trafegam entre o computador do dono e os serviços do Google/YouTube.

5. Serviços do YouTube e do Google

Este aplicativo usa os Serviços de API do YouTube. Ao usá-lo, você também concorda com os Termos de Serviço do YouTube. Os dados tratados pelo Google seguem a Política de Privacidade do Google.

6. Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Depois disso, o token salvo deixa de funcionar e pode ser apagado do computador.

7. Exclusão de dados

Para pedir a exclusão de qualquer dado, escreva para canaisdarkdozatch@gmail.com. Atendemos em até 7 dias.
